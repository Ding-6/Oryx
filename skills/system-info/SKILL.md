# 系统信息技能

## 步骤

1. 调用 `system_info` 拿到 OS、CPU、内存、磁盘、显卡。
2. 用户问"能不能跑某个游戏/软件"时，把拿到的配置和该软件的官方最低/推荐配置对比，**逐项**给结论，最后给一句总结。
3. 用户问磁盘空间时，看 `disks` 里的 `free_gb` 和 `used_percent`，指出哪个盘紧张。
4. 用户问"为什么慢"时，结合内存占用百分比和磁盘剩余空间给出可能原因，不要臆断。

## 注意

- 信息读不到时如实说"读不到"，不要编造型号。
- 不要主动执行任何修改系统的命令；如需修改设置，先说明要改什么并由用户确认。
