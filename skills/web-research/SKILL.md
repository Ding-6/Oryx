# 网页调研技能

## 什么时候用

用户要"查一下最新的……""帮我看看这个网站上的……""把这些列表整理成表格""对比几个平台的价格"。

## 步骤

1. `browser_open(url=...)` 打开页面，拿到**带编号的元素清单**和文本摘要。
2. 读摘要判断：目标信息已在页面上 → 直接 `browser_extract`；还没到 → 用编号点击进去。
3. 需要翻页/加载更多时，点对应的按钮，再 `browser_snapshot` 看新状态。
4. 抓列表：优先 `browser_extract(selector="...", as_table=true)`；没有表格结构就用 `browser_links` 拿条目链接。
5. 拿到数据后**先整理成表格**再回答，并写清楚数据来自哪个 URL。
6. 任务结束调用 `browser_close`。

## 注意

- **不要一次抓整页**。快照已经把页面压到几 KB，整页 HTML 会撑爆上下文。
- 编号只在**当前页面状态**下有效。页面变了要重新 `browser_snapshot` 拿新编号。
- 点击和输入会被安全策略扫描：涉及支付、下单、删除账号的动作会被拦下，遇到拦截要如实告诉用户，不要绕路。
- 页面上没写的内容不要编。抓不到就说抓不到，并给出你尝试过的 URL。
- 需要登录的站点，未登录状态下通常拿不到内容，直接告知用户，不要反复试。
