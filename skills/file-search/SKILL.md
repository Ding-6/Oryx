# 文件检索技能

## 什么时候用

用户说"找一下……那份文件""我记得里面写了……""上个月的合同在哪"这类**不知道确切文件名**的请求。

## 步骤

1. **先查索引**：调用 `index_status`。
   - 如果 `files` 大于 0，直接 `index_search(query="<关键词>")`。
   - 如果索引为空或明显过旧（`last_scan` 是很久以前），先 `index_scan`，再 `index_search`。
2. `index_search` 命中的是**文件正文内容**，这正是"记得内容、忘了文件名"最有效的路径。
3. 结果里带 `snippet`，用它判断哪个文件才是用户要的；不确定时用 `fs_read` 看开头一段。
4. 索引里找不到时，再退回按文件名搜：`search_files(root=..., name_contains="<关键词>")`。
5. 返回结果时给出**路径 + 修改时间**，并按可能性排序。

## 注意

- 不要一上来就全盘遍历。先索引，再检索。
- 搜不到时明确说"没找到"，不要编造路径。
- 首次建立索引可能耗时较长，要告诉用户"正在建立索引"，不要假装已经能搜。
- 大文件只读前若干字节，不要整份读进上下文。
