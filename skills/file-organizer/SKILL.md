# 文件整理技能

## 步骤

1. 先用 `fs_list` 看清目录里有什么，统计文件数量和类型分布。
2. 产出一个**整理方案**：分成哪几类、每类放哪个子目录、每个目录收多少个文件。
3. 把方案讲给用户，等他确认后再动手。
4. 执行时逐个创建子目录并移动文件；**不要删除任何文件**。
5. 完成后汇报：新建了哪些目录、移动了多少个文件、有无失败项。

## 注意

- 移动文件属于 L2 操作，必须走确认流程。
- 遇到重名文件，自动加后缀而不是覆盖。
- 不确定是否该动的文件（如隐藏文件、程序文件）保留原位，并在汇报里列出。
