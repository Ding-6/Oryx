# Oryx 内核依赖清单
#
# 为什么以前没有这个文件
# ----------------------
# 阶段一体检发现：项目**完全没有依赖清单**，环境无法复现 ——
# 「这台机器上能跑」不等于「换个机器也能跑」。
#
# 怎么维护
# --------
# 版本号取自**实际验证通过的环境**（2026-11-19），
# 不是随手抄的「最新版本」。
# 升级时改这里，然后跑：
#     pip install -r core/requirements.txt
#     python core/tests/run_pytest.py          # 全量单测
#     python core/scripts/check_api_coverage.py  # 前后端接口对齐
#
# 「必需」与「可选」的分界
# -----------------------
# 必需 = 缺了内核起不来（import 时就炸）
# 可选 = 缺了只是对应能力不可用（OCR / 向量检索 / 文档解析）
# 可选的那几个装起来很重（torch 2GB+），所以默认不装。

websockets>=12.0
PyYAML>=6.0
cryptography>=42.0

# 文档/表格处理（doc-manager 域要用）

# ── 可选：图像与 OCR ────────────────────────────────────────────────

# 没装 rapidocr 时「图片识字」工具不可用。
