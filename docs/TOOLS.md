## 注册结构：工具是怎么进来的

工具**分散注册**，所以「有哪些工具」读代码答不出来。

来源一共四条：

| 来源 | 入口 | 说明 |
|---|---|---|
| 基础工具 | `core/oryx/tools.py` 的 `build_registry()` | 文件读写、搜索、shell、系统信息等 |
| 内置扩展 | `core/oryx/loop.py` 的 `_register_*` 方法 | 下面这张表 |
| MCP | `loop.py` 的 `_register_mcp_tools()` | 名字带 `mcp__<server>__` 前缀 |
| 用户扩展 | `core/oryx/toolplug.py` | 装到用户目录的扩展，可信且允许执行时才注册 |

全部登记完之后，`AgentRuntime.refresh_tool_table()` 重建**统一工具表** —— 三种来源一张表，冲突按优先级裁定（内置 > MCP > 扩展）。

### `_register_*` 一览

| 方法 | 负责 |

| `_register_search_tools()`<br><sub>loop.py:515</sub> | |
